Terrapin-style command guide
Move and draw
FD 100 · BK 50FORWARD / BACK. Move in turtle steps.
RT 90 · LT 90RIGHT / LEFT. Turn in degrees.
SETXY [40 80]Also SETX, SETY, SETH / SETHEADING, HOME.
PU · PD · HT · STPENUP, PENDOWN, HIDETURTLE, SHOWTURTLE.
SETPC "BLUESet pen color by Logo color number, name, or [R G B].
SETWIDTH 5Also SETW, SETBG, SETOPACITY, PENERASE, PENREVERSE.
ARC 180 60Draw an arc. DOT, FILL, STAMPOVAL, STAMPRECT and TURTLETEXT also work.
CS · CLEAN · DRAWClear and home, clear only, or reset the whole drawing.
Repeat, decide, and wait
REPEAT 4 [ FD 80 RT 90 ]REPCOUNT and REPTOTAL are available inside a repeat.
IF :SIZE > 50 [ SETPC "RED ]Also IFELSE, TEST with IFT / IFF, RUN, STOP and OUTPUT.
FOR [I 1 8] [ PRINT :I ]Count through a range; add a fourth value for the step.
WHILE [ :N > 0 ] [ ... ]Also UNTIL, DO.WHILE, DO.UNTIL and FOREACH.
WAIT 250Pause for milliseconds. SETSPEED changes turtle animation speed.
SAY [HELLO VED]Speak through the browser after Run is pressed.
Procedures and variables
TO SQUARE :SIZE
REPEAT 4 [FD :SIZE RT 90]
ENDCreate a command with an input. Procedures can call themselves and other procedures.
MAKE "SIZE 80Assign a global value; read it with :SIZE or THING "SIZE.
LOCAL "X · LMAKE "X 5Create local variables inside a procedure.
OUTPUT :ANSWERReturn a value from a reporter procedure. OP is accepted.
Words, lists, math, and logic
FIRST · LAST · ITEMAccess data. Also BF / BUTFIRST, BL / BUTLAST, COUNT and PICK.
LIST · SE · WORDBuild data. Also FPUT, LPUT, SENTENCE, ISEQ, RSEQ, REVERSE and REMOVE.
SUM · DIFFERENCEAlso PRODUCT, QUOTIENT, REMAINDER, MODULO, POWER, SQRT, ABS, INT and ROUND.
SIN · COS · TAN · PIDegree trig plus ASIN, ACOS, ATAN, radians, logs, and random numbers.
= · <> · < · > · <= · >=Comparisons; AND, OR and NOT combine true/false values.
EMPTY? · MEMBER? · NUMBER?Also WORD?, LIST?, NAME?, DEFINED? and PENDOWN?.
Position reports and browser-safe I/O
POS · XCOR · YCORAlso GETXY, GETX, GETY, HEADING, TOWARDS and DISTANCE.
PRINT · SHOW · TYPESend values to Logo output; CLEARTEXT clears it.
DATE · TIME · MILLISECONDSBrowser-safe workspace reporters; CHAR and UNICODE work too.
WRAP · FENCE · WINDOWChoose how the turtle behaves at the canvas edge. GRIDON and GRIDOFF toggle the grid.
This browser interpreter follows Terrapin’s command names and abbreviations for classroom graphics and language work. Hardware robots, desktop menus, files, external widgets, and multi-window features require Terrapin Logo itself. See Terrapin’s Learning Center and complete command reference.
